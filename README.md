# Система аналітики та рекомендацій відеоігор (T-SQL / MS SQL Server)

Реляційна база даних, спроектована для збереження, структурування та аналізу даних ігрової індустрії: ігор, розробників, платформ, жанрів, профілів користувачів та їхніх відгуків.

Особлива увага в проекті приділена цілісності даних, оптимізації складних аналітичних запитів та автоматизації бізнес-процесів за допомогою тригерів у реальному часі.

## 🚀 Можливості та архітектурні рішення
* **Гнучка реляційна модель:** Нормалізована схема даних, що реалізує зв'язки «багато-до-багатьох» через проміжні таблиці зв'язку.
* **Автоматичний перерахунок рейтингів:** Складений тригер (`AFTER INSERT, UPDATE, DELETE`), який автоматично перераховує та оновлює глобальну оцінку гри у реальному часі при додаванні чи зміні відгуків.
* **Валідація на рівні СКБД:** Кастомні тригери, які захищають дані від некоректного введення (заборона від'ємних цін, оцінок поза межами 1–10, а також захист історичних дат релізу).
* **Складна аналітика:** Запити з використанням умовної логіки (`CASE`), групування та фільтрації груп (`GROUP BY`, `HAVING`), обчислення ПДВ та складних об'єднань (`JOIN`).

## 🛠️ Стек технологій
* **СКБД:** Microsoft SQL Server (MS SQL)
* **Мова запитів:** T-SQL (Transact-SQL)
* **Інструмент:** SQL Server Management Studio (SSMS)

## 📊 Даталогічна модель (Схема БД)

![Database Schema](database_schema.png)

База даних містить такі основні сутності:
* `ГРА` — каталог ігор із цінами, датами виходу та рейтингами.
* `РОЗРОБНИК` — студії розробки та їхні країни.
* `КОРИСТУВАЧ` — профілі геймерів та їхні реєстраційні дані.
* `ВІДГУК` — оцінки та тексти рецензій від користувачів.
* `ЖАНР` та `ПЛАТФОРМА` — системні довідники метаданих.

## 💾 Структура репозиторію
* `schema.sql` — створення структури таблиць, первинних та зовнішніх ключів.
* `data_insertion.sql` — наповнення бази тестовими даними (реальні ігри від HoYoverse, CD Projekt RED, Ubisoft тощо).
* `queries_and_triggers.sql` — аналітичні запити, представлення (`VIEW`) та автоматизовані тригери.

## 🛠️ Як розгорнути проект локально
1. Відкрийте **SQL Server Management Studio (SSMS)**.
2. Створіть нову базу даних: `CREATE DATABASE Курсова;`.
3. Виконайте скрипт `schema.sql` для створення таблиць.
4. Виконайте скрипт `data_insertion.sql` для завантаження даних.
5. Запустіть `queries_and_triggers.sql` для підключення тригерів та виконання аналітики.
